#  CodeAlpha Hotel Reservation System Task 4

##  Project Description
This is a Java Swing based Hotel Reservation System developed as **Task 4** of the CodeAlpha Java Programming Internship.

The system allows users to:
- View available rooms
- Book rooms
- Cancel reservation (Demo)
- Save booking details into a file


##  Features
✅ GUI Based System (Java Swing)  
✅ Room Availability Tracking  
✅ Room Booking System  
✅ Booking Data Stored in File (bookings.txt)  
✅ Simple and User Friendly Interface  


##  Technologies Used
- Java
- Java Swing (GUI)
- File Handling (FileWriter)
- VS Code
- GitHub

## 💻 System Working
1. User can check available rooms  
2. User can book Standard / Deluxe / Suite rooms  
3. Booking details get saved in bookings.txt  
4. User can exit system anytime
